# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Instead, use GitHub's private vulnerability reporting flow for this repository:

<https://github.com/kumwe/website/security/advisories/new>

Include the affected page or component, reproduction steps, impact, and any suggested mitigation. The maintainers will acknowledge the report and coordinate a responsible disclosure timeline with you.

For general support and non-security defects, open a regular GitHub issue.
